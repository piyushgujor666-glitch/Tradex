# TradeX - Trading Platform Website

TradeX is a modern responsive trading platform frontend built using HTML and CSS. The project provides a clean user interface for viewing market trends, managing portfolios, tracking assets, and accessing trading features.

## Features

- Responsive Design
- Modern Trading Dashboard UI
- Live Market Section
- Portfolio Management Page
- Login & Registration Pages
- Trading Form Interface
- Market Analytics Section
- Mobile Friendly Layout
- Clean Navigation System

## Pages
